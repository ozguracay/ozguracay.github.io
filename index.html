What I work on

LLM platforms

Deploy and operate LLM applications on Kubernetes with GPU inference on vLLM. Build RAG with dense retrieval on Qdrant, and Graph RAG with Cypher traversal over Neo4j knowledge graphs.

Evaluation and observability

Run curated test sets with LLM-as-a-judge scoring for groundedness and answer relevance before each release. Trace prompts, retrieval steps and token usage with Langfuse.

MLOps automation

Own release automation end to end with Argo CD, Terraform and GitHub Actions. Monitor LLM workloads with Grafana and Prometheus.

Data and ML platforms

Build ML platforms on Spark, Databricks, Snowflake, Airflow and Kubernetes, with feature stores and MLflow-based model monitoring.

Before LLMs: time-series forecasting with deep learning models and gradient-boosting ensembles, workforce optimization with OR-Tools, and recommendation with NLP and computer vision.
