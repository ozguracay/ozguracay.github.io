# ozguracay.github.io

Source of <https://ozguracay.github.io/>, the personal site of Ozgur Serhat Acay, Senior MLOps & ML Engineer.

One static page. `index.html` carries its own styles and structured data: no build step, no JavaScript,
no external requests. `.nojekyll` tells GitHub Pages to publish the files as they are.

`404.html` is the not-found page. `favicon.svg`, `favicon.ico`, `favicon-192.png` and `apple-touch-icon.png`
are the site icon, and `og.png` is the preview image shown when the link is shared. `robots.txt` and
`sitemap.xml` are for search engines; update the `lastmod` date in `sitemap.xml` when the page changes.

To preview, open `index.html` in a browser.
